# 五交易日价格预测基线

第一阶段提供可重复的股票代码输入与点预测，不要求先证明优于基准。完整递归自改进和精度迭代属于后续阶段。

## 运行

使用 README 中的 Python 3.12 环境和依赖：

~~~bash
export QUANT_RSI_WORKSPACE="$PWD"
quant-rsi forecast run SOXL --request-id soxl-first --output runs/soxl-first
quant-rsi forecast status soxl-first
quant-rsi forecast replay soxl-first
~~~

当前支持来源明确识别的 NYQ/PCX/ASE 市场、USD 股票/ETF；NASDAQ 等未支持市场、其他货币、资产类别或数据格式会返回可读错误。需要网络下载行情与交易所日历；离线回放不重新采集或训练。

run 保存原始响应、实际接收时间、事件 CSV、日历与单位说明。约 120 个完整日线用于训练和历史评估，日历额外包含五个交易日。收盘后 15 分钟缓冲仅为采集策略，不保证来源之后不会修订。行情遗漏不会把预测目标顺延到第六个交易日。

## 固定训练与评分

可加 --prepare-only 只采集并冻结计划，之后重跑原命令继续，不重复采集。

首次拟合前，protocol.json 固定输入哈希、训练截止点和评估索引。沿用现有 LightGBM 回归参数、24 轮、seed 7、momentum 5；每个请求只预留一次实际拟合，超时 180 秒。失败不退还预算，也不自动搜索其他模型。

N 个已完成交易日中，训练截止索引为 N−35。训练标签为 log(close[t+5]/close[t])，只用截止时已成熟的标签；历史评估从该截止点开始，每五个交易日一个 origin。固定评估网格缺少预测或标签时不产生选择分数。主指标为简单收益率误差的负 MAE，单位百分点，同时报告 RMSE。比较基准为价格不变和与模型使用相同训练样本和有效性筛选的固定标签均值；基准不增加 ML 拟合。

历史可用时间标记为明确假设，无法证明历史点时可得性。新预测使用真实观察接收时间。来源字段的 USD/每股解释是探索假设，不是经独立认证的价格口径。价格按注册表上限规范化至最多 12 位小数（half-even），原始响应保持不变。现金分红保留来源与单位绑定，不加回原始价格标签；未支持的拆股或未知行动导致拒绝/弃权，不改变账户引擎的处理规则。

## 输出与回放

输出包括数据截止时间、原始请求时间、实际生成时间、目标交易日、点预测价格/收益、模型哈希和两个基准。历史 MAE 仅是探索结果，不代表已证明的预测优势。没有经校准的概率区间。

forward 要求结果已持久提交，且提交后的确认时间早于 origin 后第一个交易日开盘。过时为 late，没有提交确认时为 unconfirmed，输入不支持时为 abstain；这些状态不会被改写为及时前瞻预测。

forecast.json 保存完整报告；research/ 保存现有 C2 研究账本。预测请求另存于当前工作区的市场注册表，绑定模型、来源、origin、target 和固定知识边界。replay 重算并核对原结果，不重新拟合。旧账户观察及 C4/C5 接口明确拒绝本预测目标。

## 重试与调度

已成功采集的完整清单原子保存在接收记录中，流程指针缺失时恢复原数据。失败或未完成且未冻结的采集可保留失败记录后新建采集尝试。

相同请求 ID 必须使用相同代码和输出目录，会复用已有采集、模型及预测。预测中断后重试原命令；结果已提交时只补提交确认，时间以实际恢复时钟为准。失败记录保留在 failures/ 和预测账本中。已耗尽的训练不会隐式再次运行。每日调度时使用新的请求 ID 和目录；不要删除账本来重试。

预测目前绑定当次源代码与运行时。发布后升级实现会使旧版本的语义回放拒绝运行；保留对应代码版本与依赖，状态和原始报告仍可查阅。数据、运行日志和本地环境保持在忽略目录内。


## 首次真实流程验证

2026-10-26 的 SOXL 验证以 120 个历史交易日、6 个固定历史评估起点完成一次训练，模型和均值基准使用相同的 76 个训练样本。结果在 10:08:39 UTC 确认持久化，目标为 2026-10-30 收盘。重复命令和只读回放与原报告完全一致，且禁止额外采集和拟合的验证通过。

预测/采集相关测试 42 项、旧本地研究/观察/研究循环回归 51 项、市场数据/保护账务/账户执行回归 27 项通过，全库 lint 和格式检查通过。未重新运行全部历史隔离测试。这验证了第一阶段功能链路，不代表已证明预测优势。运行产物保留在本地忽略目录，源码与说明纳入版本控制。
